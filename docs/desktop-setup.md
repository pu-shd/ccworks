# Set up ccworks Desktop

ccworks runs in the ChatGPT desktop app on Windows or macOS. Open the app, select your organization workspace, and start a local Work session.

1. Install **ccworks Desktop** and your organization's approved Chrome or Chromium browser from the software catalog if IT has not already installed them.
2. Open the organization's private ccworks link in ChatGPT and install the plugin if it is not already available in your workspace.
3. Open **ccworks Desktop** from Start on Windows or Finder on macOS. Select **Sign in to Concur**.
4. Complete your organization's SSO and MFA in the browser. When the Concur expense dashboard appears, return to **ccworks Desktop** and select **Done**. Wait for **Ready**.
5. Return to your local Work session and ask ccworks to inspect your statement.

If IT supplies a Windows self-service installer, open it from your downloads and follow the prompts. On macOS, open the disk image. In Finder, choose **Go > Home**, create an **Applications** folder there if needed, and drag the app from the disk image into that folder. Open the installed copy. Use the catalog again for updates on managed installs. On self-service builds, look for **Check for Updates…** in the **ccworks Desktop** menu on macOS or in the setup window on Windows. Replacing the app preserves your sign-in when that session is still valid.

If sign-in expires, repeat steps 3 and 4. Select **Cancel** to stop a new sign-in and keep your saved session. If a Concur update was interrupted, ask ccworks to inspect the saved report before trying the update again.

## Remove ccworks

- Finish any ccworks operations and close the Work session. Open **ccworks Desktop** and select **Remove ccworks data** to clear the saved sign-in and ccworks temporary data.
- Windows users can also select the data cleanup option during uninstall. Open **Settings > Apps > Installed apps**, find **ccworks Desktop**, and select **Uninstall**.
- On macOS, move **ccworks Desktop** to Trash after clearing its data. Use your software catalog for removal if IT installed the app there.
- Remove the ccworks plugin separately in ChatGPT. Contact IT if the organization manages the plugin or helper through policy.

Data removal leaves your Concur records, receipt files, approved browser, and personal browser profile in place.
